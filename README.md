# Roblox Up-and-Coming Forecast — v3

Entry for the make.fun bounty roblox-up-and-coming-forecast-01: a program
that forecasts Roblox's Up-and-Coming top 10 for the 72 hours after entries
close. A stack of two forecasters (Python 3.13, stdlib only, offline,
deterministic): the v2 Monte Carlo rank simulation (90%) plus a fitted
Gaussian place-occupancy table (10%). See BUILD_NOTES.md for the method,
the validation scores, and the honest caveats.
